Le Chonk plays DOOM

A DOOM-like first-person shooter, built so that Mistral Large 4 can play it by itself: it sees the screen, aims with a degree ruler, explores with an automap, opens doors with keys and fights its way to the EXIT, with a big fat cat attitude.

🐱 Watch Le Chonk play (no key needed) 📊 See the benchmark

The game

The house has been invaded by angry dogs and mice. Le Chonk, a very large and very proud orange tabby, grabs his laser pistol. Three levels (Le Salon → La Cuisine → La Cave), colored keys and locked doors, a secret wall, explosive barrels and REX, an armored Doberman boss.

  • 🎯 Real-time 3D FPS (three.js), not a grid game: perception from pixels, aiming, dodging, navigation.
  • 🔫 DOOM arsenal: fist, laser pistol, shotgun, chaingun.
  • 🐶 Mice throw cheese, chihuahuas fire sonic yaps, bulldogs charge, Rex throws bones.
  • 🎨 Everything is generated in code: pixel art (Resurrect 64 palette), the reactive DOOM-style face, 4 chiptune tracks, sound effects. No asset files.
  • 🧑 Fully playable by humans too: arrows + space.

The harness

A frontier model needs seconds per decision; a shooter runs at 60 fps. So for Le Chonk the game is turn-based: time freezes while he thinks, then his actions run in real time while enemies act, and anything surprising interrupts him.

1Observe

The frame (768×480) + a text observation: status, events, ASCII automap, known doors, items and EXIT, his own notes.

→
2Think

mistral-large-4 via the Vercel AI SDK. Last 4 turns in context (text only), only the current image.

→
3Act

One forced tool call: act({ thought, actions[1..8], notes }).

→
4Execute

Macro-actions turned into 60 Hz inputs. Movement stops the instant he's hurt or a new enemy appears.

wait {seconds}let them come around the corner
noteshis own long-term memory, shown back every turn

Because interrupts make long plans safe, Le Chonk plans long when it's calm (explore → grab the key → go to the door → explore) and short in combat (attack, strafe, attack). Fewer model calls = faster and cheaper.

Benchmark: open-weight models

Same game, same harness, same prompt, only the model changes. Open-weight models only, in two leagues so reasoning and non-reasoning models are never mixed. Each episode = one level, capped at 150 / 220 / 260 turns and 3 deaths, Medium difficulty, via Mistral Studio or OpenRouter (real reported costs).

The benchmark is running… results will appear here.

What the columns mean

Cleared: EXIT pressed. Turns: model calls. Actions: macro-actions executed. Game time: simulated time. Wall time: real time including model latency. Hit rate: shots that hit an enemy. Aim error: |commanded angle − true angle of the nearest visible enemy| at each attack (median). Cost: real cost reported by OpenRouter.

Evals

Unit tests of the two skills the harness relies on, written with Evalite (TypeScript, Vitest). Scenes are staged in the real engine (an enemy at a known angle, a known key with a locked door, low health with food nearby, a bulldog charging, the EXIT in front…) and each model must answer with the right act(). 3 trials per case.

Bloopers & honesty

🧀 "The milk bottle"

Le Chonk kept trying to drink a green spray can labelled "NIP"… it was an explosive barrel. He bumped into it three times. Fix: classic red barrels with a hazard sign, and "BLOCKED by an explosive barrel (not an item)" feedback.

🗺️ Counting columns is hard

After clearing Level 1 completely, he read the EXIT at (28,23) and then (25,23) instead of (24,23), and wandered. Fix: the observation now lists doors, items and the EXIT with exact coordinates, and go_to the EXIT walks there and presses it.

🐭 "Right in my face at 0°… 0 hits"

Mice in melee range were too thin to hit. DOOM has generous hitboxes; now so do we.

🔢 5 or S?

The pixel font made "+15" on the ruler look like "+1S". For a model that aims by reading digits, that matters: numbers now use Press Start 2P.

Small models (Ministral 8B/14B, Pixtral) answer ±15° when the bulldog is at 0°, and get stuck in the first room. Mistral Large 4 reads the ruler and clears the levels.

Reproduce it

No install

Open the game, click Let Le Chonk Play, then Watch Replay (no key), or paste a Mistral Studio / OpenRouter key and press Start Le Chonk.

Locally

git clone https://github.com/goums/chonk-doom
cd chonk-doom && npm install
echo "MISTRAL_STUDIO_API_KEY=…" > .env
echo "OPEN_ROUTER_API_KEY=…" >> .env
npm run dev          # play / watch
npm run bench -- --provider openrouter \
  --models mistralai/mistral-large-4-0 --runs 3
npm run eval         # Evalite evals
